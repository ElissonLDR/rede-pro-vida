# Rede Pró Vida

Você é um desenvolvedor frontend especialista em UX/UI e CRO (Conversion Rate Optimization). Crie uma Landing Page moderna, elegante e de altíssima conversão para a clínica "Rede Pró Vida Belém", utilizando Tailwind CSS, Lucide Icons, e componentes do Shadcn/UI (React).

---

### 🎨 REQUISITOS DE DESIGN E IDENTIDADE VISUAL

1. **Logo e Identidade**:

   - Utilize a logo oficial do cliente capturada do site institucional `redeprovidabelem.com.br` no cabeçalho e no rodapé.

   - Preserve o ícone característico da marca (coração/pulso/saúde) em elementos gráficos e favicons.

2. **Paleta de Cores**:

   - **Cor Primária / Fundo de Destaque**: Azul Petróleo / Teal escuro (`#0A3B4A` ou similar).

   - **Cor Secundária / Accent**: Coral / Laranja suave para destaques e emblemas.

   - **Cor de Conversão (CTA Principal)**: Verde WhatsApp (`#25D366` / `#128C7E` no hover) com alto contraste em todas as seções.

   - **Fundo de Seções**: Alternar entre Branco Puro (`#FFFFFF`), Cinza/Azul Ultraleve (`#F4F7F6`) e Petróleo Escuro (`#0A3B4A`) para criar ritmo visual.

3. **Tipografia & Layout**:

   - Fonte sans-serif moderna, limpa e altamente legível (ex: Inter ou Plus Jakarta Sans).

   - Design 100% responsivo (Mobile-First): Botões de CTA fixos no rodapé no mobile (Sticky CTA bar).
